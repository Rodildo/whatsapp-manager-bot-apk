# WhatsApp Manager Bot — Descargas

Este repositorio solo sirve para publicar el APK de **WhatsApp Manager Bot**, la app
que instalan los negocios para configurar y controlar su asistente de WhatsApp con IA.

No contiene el codigo fuente de la app ni del bot (esos siguen en repositorios privados).

## Descargar

La ultima version del APK esta siempre en la seccion **Releases** de este repositorio:

https://github.com/Rodildo/whatsapp-manager-bot-apk/releases

Descarga el archivo `.apk` de la version mas reciente e instalalo en un telefono Android
(hay que permitir "instalar apps de origenes desconocidos" la primera vez).
